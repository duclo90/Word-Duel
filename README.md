# Word Duel

**Word Duel** is a browser-based multiplayer word game where players compete in real-time to form words from a shared set of letters. Challenge your friends or play solo and test your vocabulary and speed!

## 🎮 Features

- **Two-Player Mode:** Compete with a friend in real-time.  
- **Shared Letter Pool:** Both players use the same set of letters to form words.  
- **Time Challenge:** Think fast! Each round has a countdown timer to keep the game exciting.  
- **Word Tracking:** Prevent repeated words with a “Used Words” list.  
- **Easy Access:** No registration or downloads required—play directly in your browser.

## 🚀 How to Play

1. Open [Word Duel](https://word-duel-mygame.vercel.app/main/main.html) in your browser.  
2. Start a new game and invite a friend.  
3. Use the letters provided to form words as quickly as possible.  
4. Submit your words before the timer runs out.  
5. Check the “Used Words” list to avoid duplicates.  
6. The player with the most valid words at the end wins!
